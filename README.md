# 커피내기 구슬 경주

브라우저에서 실행하는 정적 웹앱입니다. 로그인, 서버, 데이터베이스 없이 동작합니다.

## 실행 방법

- `index.html`을 최신 데스크톱/모바일 브라우저에서 엽니다.
- 또는 프로젝트 폴더를 로컬 정적 파일 서버로 제공하고 `index.html`에 접속합니다. 빌드나 패키지 설치는 필요하지 않습니다.
- Google Fonts를 불러올 수 없는 환경에서는 시스템 글꼴 대체 글꼴을 사용합니다.

## 플레이 방법

1. 이름을 줄바꿈·쉼표·탭으로 구분해 한 번에 붙여넣습니다. `홍길동 * 5, 김민지, 이준호 * 2`는 3명·8개 구슬입니다. 같은 이름은 같은 사람으로 묶고 색·무늬를 통일하며, 각 구슬에는 고유 번호를 배정합니다. 전체 구슬 수는 2~100개입니다. 기존 기본 이름 자동 채우기도 사용할 수 있습니다.
2. 맵과 플레이 모드를 선택합니다. 일반 경주는 황금구슬 이벤트를 선택할 수 있습니다. 경기당 10% 확률로 구슬 하나가 31종 중 능력 하나를 받습니다. 능력 배틀은 모든 구슬이 같은 31종 중 능력 하나를 받아 자동 발동하며 황금구슬을 함께 사용하지 않습니다. 시작하면 3·2·1 카운트다운 뒤 경주합니다.
3. 구슬을 클릭/터치하면 참가자 이름이 표시됩니다. 한 손가락이나 마우스 드래그로 카메라를 옮기고, 두 손가락을 벌리거나 모으거나 마우스 휠로 확대·축소합니다. 실시간으로 결승선을 통과한 순서가 오른쪽 목록에 추가됩니다.
4. 모든 구슬이 완주하면 구슬별 전체 순위와 마지막 구슬의 주인인 커피 당첨자를 확인합니다. 여러 구슬을 가진 사람은 `홍길동 · 2/5번 구슬`처럼 표시합니다. 같은 설정으로 재경기하거나 참가자·맵을 바꿀 수 있습니다.
5. 배틀이나 황금구슬이 나온 경기에서는 구슬을 추적하거나 ‘내 구슬 능력’을 열어 설명·발동 상태·다음 발동까지 남은 시간을 확인합니다. 목록을 보는 동안 경주는 잠시 멈추며 원래 일시 정지 상태도 유지합니다.

### 스물두 번째 버전 · 계곡 경로 다양화와 맵 테마 색상

- 계곡의 물살을 2~3갈래의 굽은 물길로 나누고 일부 교차 급류는 서로 다른 주기로 켜졌다 꺼집니다. 가장자리에서는 주 급류가 약해지고 작은 되돌이 흐름이 안쪽으로 휘어집니다.
- 비대칭 바위섬 7개와 물살이 없는 쉼 구간 5곳을 추가했습니다. 마지막 출구의 무급류 구간은 유지합니다.
- 공장은 금속 청회색과 주황 안전색, 계곡은 청록 물과 녹색 강둑, 유적은 회색 석재와 이끼색으로 바닥·벽·일반 장애물·미니맵을 맞췄습니다.
- 고정된 100개 구슬 비교 조건에서 가장자리 체류가 48.1%에서 35.9%로 줄었습니다. 변경과 검증 범위는 `UPDATE_V22.md`를 참고하세요.

### 열세 번째 버전 · 황금구슬 광채와 특수 효과 조정

- 황금구슬의 굵은 바깥 원을 없앴습니다. 본체와 충돌 크기는 일반 구슬과 같고, 은은한 광채와 세 개의 작은 별 반짝임으로 구분합니다.
- 자석은 150→175, 바람은 230→270으로 약 17% 강화했습니다. 영향 범위는 그대로이며 자석 표면 가까이에서는 인력이 줄어듭니다.
- 일반 24경기·황금구슬 18경기·여러 구슬 소유 3경기와 자석 접촉면 양옆 탈출을 검증했습니다. 자세한 내용은 `UPDATE_V13.md`를 참고하세요.

### 열두 번째 버전 · 히든 황금구슬

- 경기당 10% 확률로 전체 구슬 중 하나가 황금구슬로 바뀝니다. 구슬 수와 무관하게 한 번 추첨하며, 등장했다면 세 능력 중 하나를 같은 확률로 받습니다.
- **지름길**: 1구간을 건너뛰고 2구간의 빈 위치에서 출발합니다.
- **헤비볼**: 하강력이 조금 강하고, 다른 구슬과 부딪힐 때 덜 밀립니다.
- **자석·바람 면역**: 자석과 바람의 힘을 무시하며 기본 중력과 장애물 충돌은 유지합니다.
- 금빛 등장 연출 동안 잠시 출발을 기다린 뒤 자동 중계로 돌아갑니다. 황금구슬의 번호·소유자·무늬는 유지하며 능력은 한 구슬에만 적용됩니다. 순위와 결과에도 능력을 표시합니다.
- 자세한 규칙과 검증은 `UPDATE_V12.md`를 참고하세요.

### 여섯 번째 버전 · 일괄 입력과 여러 구슬 배정

- 엑셀 이름 열, 줄바꿈·쉼표·탭으로 구분한 명단을 한 번에 붙여넣습니다.
- `홍길동 * 5` 또는 `홍길동 × 5`로 같은 사람에게 여러 구슬을 배정합니다. 반복한 이름은 합산하며 미리보기에서 인원과 구슬 수를 따로 확인합니다.
- 동일인의 구슬은 색상과 무늬가 같고, 구슬 번호 및 소유자 내 순번으로 구분합니다. 출발 위치는 매 경기 섞습니다.
- 개수는 양의 정수, 전체 구슬은 2~100개로 제한합니다. 0·음수·소수·잘못된 표기·합계 초과는 안내 후 진행을 막습니다.
- 로그인·명단 저장 없이 현재 화면에서만 사용합니다. 검증 결과는 `UPDATE_V6.md`를 참고하세요.

### 다섯 번째 버전 · 끼임 개선과 수동 카메라

- 회전 맵의 슬라이딩 블록 옆 자석을 왼쪽으로 옮겨 판의 전체 이동 범위와 사이에 통과 공간을 확보했습니다.
- 정체 복구 버튼은 위·옆으로 강하게 튀깁니다. 잠시 속도 제한을 높이고 자석의 당기는 힘을 쉬게 해 다시 붙는 현상을 줄였습니다.
- 미니맵에서 보고 싶은 위치를 클릭하면 수동 보기로 이동합니다. 확대 상태에서 경주 화면을 드래그하면 가려진 좌우도 볼 수 있습니다.
- 수동 보기는 선택한 위치를 유지합니다. 휠 확대·축소와 구슬 클릭 추적도 사용할 수 있고, **자동** 버튼으로 중계에 복귀합니다.
- 미니맵에 키보드 초점을 둔 뒤 방향키로 위치를 조정할 수도 있습니다.
- 현재 검증 결과는 `UPDATE_V5.md`를 참고하세요.

### 네 번째 버전 · 밀집 장애물과 네 종류의 골키퍼

- 여섯 구간의 길이를 약 두 배로 확장했습니다. 핀볼 7,200m, 회전 장애물 7,800m, 갈림길 8,400m입니다.
- 고정 핀·범퍼만 각각 458개, 435개, 386개가 있으며, 여기에 회전문·이동 블록·수비 막대가 더해집니다.
- 모든 구간에 강한 반발력의 **파워 범퍼**, 구슬을 끌어당기는 **자석**, 옆으로 미는 **바람**을 섞었습니다. 범퍼 충돌에는 빛과 짧은 이동 흔적을 표시합니다.
- 회전 장애물·갈림길 맵은 옆 벽의 굴곡, 통로 폭과 벽 두께가 달라집니다.
- 골키퍼는 경기 시작 시 슬라이딩·회전 방패·쌍문·진자 중 하나를 각 25% 확률로 뽑습니다. 한 경기에서는 같은 종류를 유지하며, 재경기 시 새로 추첨합니다.
- 마지막 구간의 시작·중간에는 수비 막대와 작은 수비 장애물을 배치했습니다. 구슬 지름 2.5배 출구는 유지합니다.
- `course.js`는 코스 생성·특수 효과·골키퍼를 담당합니다. 충돌 후보는 구간별 버킷으로 나눠 계산합니다.

### 세 번째 버전 · 휠 줌, 추가 구간과 골키퍼

- 경주 화면 위에서 마우스 휠을 올리면 확대하고 내리면 축소합니다. 기존 버튼도 사용할 수 있으며, 확대 범위는 0.8~4.0배입니다.
- 각 맵에 두 구간을 추가해 총 여섯 구간으로 구성했습니다. 핀볼은 3,600m, 회전 장애물은 3,900m, 갈림길은 4,200m입니다.
- 링 범퍼·스윙 브리지, 슬라이딩 블록·삼중 회전문, 다이아몬드 미로·움직이는 징검다리가 추가되었습니다. 핀·범퍼·막대의 크기와 두께도 서로 다릅니다.
- 모든 맵의 출구는 해당 경기 구슬 지름의 2.5배입니다. 벽 두께를 제외한 실제 내부 통로 폭을 기준으로 계산합니다.
- 결승선 앞에는 좌우로 왕복하는 골키퍼 패들이 있습니다. 패들이 통로 밖으로 이동하는 순간에는 통과할 수 있습니다.

### 두 번째 버전 · 카메라 중계와 코스 개선

- 경주 창을 현재 브라우저 높이에 맞춰 페이지 스크롤 없이 관람할 수 있게 했습니다.
- 자동 중계가 선두·중간 그룹·후미를 따라갑니다. 드롭다운으로 시점을 고르거나 특정 참가자를 추적하고 확대·축소할 수 있습니다.
- 구슬을 클릭하거나 터치하면 해당 참가자를 추적합니다. 오른쪽 미니맵에서 전체 코스와 현재 카메라 위치를 확인할 수 있습니다.
- 핀볼(2,400m): 핀 숲, 범퍼 정원, 지그재그 슬라이드
- 회전 장애물(2,600m): 회전 날개, 엇갈린 회전문, 더블 게이트
- 갈림길(2,800m): 첫 번째 분기, 교차 합류, 마지막 선택
- 거리는 게임 내부의 코스 눈금입니다. 초기 버전의 코스 길이는 1,600이었습니다.
- 도착자가 나오기 전에는 현재 위치 기준 선두 그룹을 보여주고, 도착 후에는 확정 도착 순서를 보여줍니다.

두 번째 버전의 변경과 확인 결과는 `UPDATE_V2.md`에 기록했습니다. 아래는 첫 번째 버전의 변경 이력입니다.

- 세 맵을 세로로 긴 레이스 트랙으로 확장했고, 거리 눈금으로 코스 진행을 확인할 수 있습니다.
- 맵마다 결승선은 하나의 좁은 게이트로 통일했습니다. 트랙을 내려오며 결승 게이트 안에서 실제 결승선을 통과해야 순위에 기록됩니다.
- 갈림길의 각 경로 폭을 넓히고, 아래쪽에서 다시 합류하도록 조정했습니다.

경기는 고정 시간 간격의 자체 2D 물리 시뮬레이션으로 진행합니다. 구슬 충돌 후보는 공간 격자로 줄입니다. 정체가 감지되면 물리적 밀어주기를 시도하고, 복구가 되지 않으면 미완주 참가자를 임의 꼴찌 처리하지 않고 경기를 멈춥니다.

## 확인 범위와 한계

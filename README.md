## 플레이 방법

1. 이름을 줄바꿈·쉼표·탭으로 구분해 한 번에 붙여넣습니다. `홍길동 * 5, 김민지, 이준호 * 2`는 3명·8개 구슬입니다. 같은 이름은 같은 사람으로 묶고 색·무늬를 통일하며, 각 구슬에는 고유 번호를 배정합니다. 전체 구슬 수는 2~1,000개입니다. 수동 명단도 ‘1인당 구슬 수’와 −/＋로 공통 수량을 바꿀 수 있고 기본 이름 자동 채우기도 사용할 수 있습니다. 커피 당첨 등수는 꼴찌·1등·직접 지정 중 선택합니다.
2. 맵과 플레이 모드를 선택합니다. 일반 경주는 황금구슬 이벤트를 선택할 수 있습니다. 경기당 10% 확률로 하나가 선택되며, 해당 경기의 15%에서는 히든 혜성 질주를, 나머지에서는 일반 50종 중 하나를 받습니다. 능력 배틀은 모든 구슬이 일반 능력을 받고 경기당 3% 확률로 하나의 능력이 혜성 질주로 교체됩니다. 시작하면 3·2·1 카운트다운 뒤 경주합니다.
3. 구슬을 클릭/터치하면 참가자 이름이 표시됩니다. 한 손가락이나 마우스 드래그로 카메라를 옮기고, 두 손가락을 벌리거나 모으거나 마우스 휠로 확대·축소합니다. 미니맵을 누른 채 끌면 해당 위치를 연속해서 볼 수 있습니다. 경기 배속은 0.25·0.5·1·2·4배 중 선택하며 새 경기는 1배로 시작합니다. 실시간으로 결승선을 통과한 순서가 오른쪽 목록에 추가됩니다.
4. 모든 구슬이 완주하면 구슬별 전체 순위와 설정한 등수의 커피 당첨자를 확인합니다. 여러 구슬을 가진 사람은 `홍길동 · 2/5번 구슬`처럼 표시합니다. 같은 설정으로 재경기하거나 참가자·맵을 바꿀 수 있습니다. 실시간 도착 순서는 최근 100개를 보여 주고 최종 결과에는 전체 순위를 표시합니다. 대규모 경기의 재생 속도는 기기 성능에 따라 낮아질 수 있습니다.
5. 배틀이나 황금구슬이 나온 경기에서는 구슬을 추적하거나 ‘내 구슬 능력’을 열어 설명·발동 상태·다음 발동까지 남은 시간을 확인합니다. 목록을 보는 동안 경주는 잠시 멈추며 원래 일시 정지 상태도 유지합니다.

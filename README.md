# Coffee Marble 커피마블

브라우저에서 즐기는 무료 커피내기 구슬 경주입니다. 참가자 명단과 맵, 당첨 등수를 정하고 경주 결과를 확인하세요. 로그인이나 설치 없이 사용할 수 있습니다.

- [게임 실행](https://rockcandy444.github.io/coffeemarble/)
- [소스 저장소](https://github.com/RockCandy444/coffeemarble)

푸터에서 한국어·English·日本語를 선택할 수 있습니다. 같은 탭에서 언어를 바꾸어도 입력한 이름과 설정은 유지됩니다. [English](https://rockcandy444.github.io/coffeemarble/en/) · [日本語](https://rockcandy444.github.io/coffeemarble/ja/)

## 사용 방법

1. 참가자 이름을 줄바꿈·쉼표·탭으로 구분해 붙여넣습니다. 엑셀 이름 열도 사용할 수 있습니다.
2. `홍길동 * 5`처럼 입력하면 같은 참가자의 구슬을 여러 개 만듭니다. 같은 사람은 같은 색·무늬를 사용하며 전체 구슬은 2~1,000개까지 지원합니다.
3. ‘1인당 구슬 수’로 수동 입력한 명단의 공통 수량도 바꿀 수 있습니다. 이름 없이 시작하려면 ‘기본 이름으로 채우기’를 사용하세요.
4. 당첨 등수는 꼴찌·1등·직접 지정 중 선택합니다. 맵과 일반/능력 배틀 모드를 고르고 시작하세요.
5. 결승선을 실제로 통과한 순서대로 순위가 정해집니다. 설정한 등수의 구슬 주인이 커피 당첨자가 됩니다.

일반 경주는 황금구슬 이벤트를 선택할 수 있습니다. 능력 배틀에서는 구슬마다 자동 발동 능력을 받습니다. 능력은 경기 화면의 ‘내 구슬 능력’에서 확인할 수 있습니다.

## 경주 조작

- 마우스 드래그 또는 한 손가락으로 카메라를 이동합니다.
- 마우스 휠이나 두 손가락으로 확대·축소합니다.
- 미니맵을 클릭하거나 누른 채 끌어 원하는 구간으로 이동합니다.
- 카메라 메뉴에서 자동 중계·참가자 추적·당첨 등수 따라가기를 선택할 수 있습니다.
- 0.25·0.5·1·2·4배속과 일시 정지를 지원합니다. 새 경주는 1배속으로 시작합니다.
- 구슬이 오래 멈추면 화면의 복구 안내를 사용할 수 있습니다. 미완주 구슬을 임의로 꼴찌 처리하지 않습니다.

구슬 수가 많은 경기에서는 기기 성능에 따라 재생 속도가 낮아질 수 있습니다.

## 로컬 실행

프로젝트 폴더를 정적 HTTP 서버로 제공하면 언어별 주소를 포함해 실행할 수 있습니다. 이미 생성된 HTML을 제공하므로 패키지 설치나 서버 측 처리는 필요하지 않습니다. Google Fonts를 불러올 수 없는 환경에서는 대체 글꼴을 사용합니다.

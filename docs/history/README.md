# 이전 버전 요약

현재 사용 방법은 [README](../../README.md), 최근 변경 사항은 [CHANGELOG](../../CHANGELOG.md)를 참고하세요.

| 단계 | 주요 개선 |
| --- | --- |
| 초기 버전 | 참가자 입력, 기본 3개 코스, 실제 결승 통과 순위 |
| 경주 화면 | 고정된 경주 창, 이동·확대축소 카메라, 미니맵 |
| 코스 확장 | 장애물 종류와 구간 구조 다양화, 출구와 골키퍼 개선 |

| 맵 다양화 | 컨베이어 공장, 급류 계곡, 붕괴하는 유적과 구간별 기믹 |
| 모바일 조작 | 두 손가락 확대축소, 기능 버튼과 정보 배치 개선 |
| 운영 준비 | 무료 공개 배포, 당첨 등수 설정, 최대 1,000개 구슬 |
